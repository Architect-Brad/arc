# Asset credits

## arc's own logos

`arc-logo.svg` (600 x 200) and `arc-icon.svg` (128 x 128) are original work created for arc and released under arc's MIT license (see the repository `LICENSE`). They have transparent backgrounds and use only inline SVG paths, shapes, and text; there are no external assets or embedded images.

Usage:

```html
<img src="assets/arc-logo.svg" alt="arc">
<img src="assets/arc-icon.svg" alt="arc" width="32" height="32">
```

The icon is designed to remain recognizable at 32 px. Both files include `<title>` and `<desc>` for assistive technology.
